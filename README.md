# Monitor de turnos V2

Versión independiente del monitor original. Consulta la web cada cinco minutos,
detecta directamente la sede habilitada, las fechas del calendario y los horarios.

También mantiene las últimas 30 consultas en una variable persistente de GitHub y
acepta comandos por Telegram:

- `/estado`
- `/ultima`
- `/historial`
- `/pausar`
- `/reanudar`

Consulta `INSTRUCCIONES-V2.txt` para instalarlo sin modificar el bot anterior.
La comparación real entre ambos estados está documentada en
`REFERENCIA-DISPONIBILIDAD.txt`.
